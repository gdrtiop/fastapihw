# Важно!
Лежит только `.env.example`, чтобы всё работало нужно создать свой `.env` в соответвствии с примером
## Запуск
стандартный `docker compose up --build`
## Обоcнование кэширования
- Кэшируем `GET /tasks`, т.к. очень это самый частый запрос, при этом данные меняются реже, следоватльно можем кэшировать, а при создании, удалении и изменении сбрасывать кэш
- Кэшируем  `GET /tasks/top?n=N` аналогично первому, только скорее всего пользователь будет менять сортировку, чаще, но не каждый раз, поэтому тоже имеет смысл
